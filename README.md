**Brain Battle**

**Project Description**
Brain Battle is a simple math quiz game created using Flowgorithm. It tests the player's math skills through three questions.

**Features:**
1. Three math questions
2. Checks the player's answers
3. Tracks the player's score
4. Displays the final score

**Technologies Used:**
Flowgorithm and GitHub

**How to Play:**
1. Run the flowchart in Flowgorithm.
2. Read each math question.
3. Enter your answer.
4. Check your final score.
