Brain Battle

Project Description

Brain Battle is a simple math quiz game created using Flowgorithm. It tests the player's math skills through three questions.

Features

Three math questions

Checks the player's answers

Tracks the player's score

Displays the final score

Technologies Used

Flowgorithm

How to Play

Run the flowchart in Flowgorithm.

Read each math question.

Enter your answer.

Check your final score.
